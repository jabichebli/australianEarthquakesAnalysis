## Description  
This interactive analysis explores seismic activity across Australia from 2008 to 2024, highlighting key trends, regional risks, and the relationship between earthquake magnitude, depth, and resulting damage. By visualizing earthquake data, this project provides valuable insights into Australia's lesser-known seismic activity and the impact of these events on various regions. The analysis aims to inform infrastructure planning, especially in regions near active tectonic boundaries, and offers a deeper understanding of Australia's earthquake risks.

## Data  
The dataset used in this analysis came from [Geoscience Australia](https://earthquakes.ga.gov.au/).

## Analysis Types  
This visualization includes multiple data exploration techniques, including:

1. **Earthquake Magnitude and Depth Analysis** - Exploring the correlation between earthquake magnitude, depth, and their associated impacts.
2. **Regional Seismic Activity Breakdown** - Identifying regions of Australia with the highest seismic activity.
3. **Time Series Trends** - Tracking the frequency and intensity of earthquakes over the years.
4. **Risk and Impact Assessment** - Analyzing the effects of earthquakes on infrastructure and communities.
5. **Interactive Visualizations** - Dynamic charts and maps for deeper user exploration.

## Specific Data Analysis Techniques  
In this analysis, various technical data analysis techniques and visualizations were employed to explore earthquake trends and impacts. Below is a list of the specific techniques and charts used:

- **Donut Plot**
- **Choropleth Plot**
- **Bubble Plot**
- **Radial Bar Plot**
- **Bubble Map Plot**
